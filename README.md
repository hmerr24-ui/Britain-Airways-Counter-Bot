# Britain Airways Counter Bot v3

Commands:
- `/counter create`
- `/counter edit`
- `/counter refresh`
- `/counter delete`

Railway variables:
- DISCORD_TOKEN
- CLIENT_ID
- GUILD_ID
- PILOT_ROLE_ID
- VERIFIED_ROLE_ID

Discord bot permissions:
- View Channels
- Send Messages
- Embed Links
- Manage Channels

Privileged intent:
- Server Members Intent

Pilot and Verified counters use the configured role IDs.
Flights Completed is reserved for the Pilot Tracker integration.
